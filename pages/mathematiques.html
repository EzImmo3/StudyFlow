Équation 2nd degré

Résolution : ax² + bx + c = 0

Δ = b² - 4ac Si Δ > 0 → 2 racines : x₁ = (-b - √Δ) / 2a x₂ = (-b + √Δ) / 2a Si Δ = 0 → 1 racine : x₀ = -b / 2a Si Δ < 0 → Pas de racine réelle
Équation 2nd degré

Forme factorisée & canonique

Forme factorisée (si Δ ≥ 0) : f(x) = a(x - x₁)(x - x₂) Forme canonique : f(x) = a(x - α)² + β α = -b/2a (sommet) β = f(α) (valeur minimale/maximale)
  • α est l'axe de symétrie de la parabole
  • Si a > 0 : parabole "souriante", minimum en α
  • Si a < 0 : parabole "triste", maximum en α
Équation 2nd degré

Signe de ax² + bx + c

  • Δ > 0 : f(x) du signe de a à l'extérieur des racines, signe opposé à a entre les racines
  • Δ = 0 : f(x) du signe de a, s'annule en x₀
  • Δ < 0 : f(x) toujours du signe de a (jamais nul)
Somme des racines : x₁ + x₂ = -b/a Produit des racines : x₁ × x₂ = c/a
Suites

Suite arithmétique

Raison r = uₙ₊₁ - uₙ (constante) Terme général : uₙ = u₀ + n·r uₙ = u₁ + (n-1)·r Somme de n+1 termes (u₀ à uₙ) : S = (n+1) × (u₀ + uₙ) / 2
Suites

Suite géométrique

Raison q = uₙ₊₁ / uₙ (constante, q ≠ 0) Terme général : uₙ = u₀ × qⁿ Somme de n+1 termes (u₀ à uₙ) : S = u₀ × (1 - qⁿ⁺¹) / (1 - q) si q ≠ 1
  • Si |q| < 1 → uₙ → 0 (suite converge vers 0)
  • Si q > 1 → uₙ → +∞
  • Si q < -1 → |uₙ| → +∞ (diverge)
Suites

Sens de variation

  • Arithmétique : croissante si r > 0, décroissante si r < 0
  • Géométrique : Dépend du signe de q et de u₀
  • Méthode : Calculer uₙ₊₁ - uₙ (arithm.) ou uₙ₊₁/uₙ (géom.) et étudier le signe
  • Suite définie par récurrence : chercher une suite auxiliaire vₙ = uₙ - L (L = limite présumée)

Trigonométrie

Cercle trigonométrique & angles

  • Cercle de rayon 1 centré en O
  • M(cos θ, sin θ) sur le cercle
  • cos est pair : cos(-θ) = cos(θ)
  • sin est impair : sin(-θ) = -sin(θ)
  • Période 2π : cos(θ+2π) = cos(θ)
Produit scalaire

Définitions

u⃗·v⃗ = |u⃗|·|v⃗|·cos(θ) (θ = angle entre u⃗ et v⃗) Si u⃗(x;y) et v⃗(x';y') : u⃗·v⃗ = xx' + yy' Si A, B, C sont des points : AB⃗·AC⃗ = (xB-xA)(xC-xA) + (yB-yA)(yC-yA)
Produit scalaire

Applications géométriques

  • Orthogonalité : u⃗ ⊥ v⃗ ⟺ u⃗·v⃗ = 0
  • Norme : |u⃗|² = u⃗·u⃗ = x² + y²
  • Angle entre deux vecteurs : cos θ = u⃗·v⃗ / (|u⃗|·|v⃗|)
  • Distance AB : AB = √((xB-xA)² + (yB-yA)²)
Identités remarquables : |u⃗+v⃗|² = |u⃗|² + 2u⃗·v⃗ + |v⃗|² |u⃗-v⃗|² = |u⃗|² - 2u⃗·v⃗ + |v⃗|²
Probabilités

Probabilités de base

P(A ∪ B) = P(A) + P(B) - P(A ∩ B) P(Ā) = 1 - P(A) P(A ∩ B) = P(A) × P(B|A) Si A et B indépendants : P(A ∩ B) = P(A) × P(B)
Probabilités

Probabilité conditionnelle

P(B|A) = P(A ∩ B) / P(A) (si P(A) ≠ 0) Formule des probabilités totales : Si B₁, B₂... partition de Ω : P(A) = P(A|B₁)P(B₁) + P(A|B₂)P(B₂) + ...
Probabilités

Loi binomiale B(n, p)

X ~ B(n, p) P(X = k) = C(n,k) × pᵏ × (1-p)ⁿ⁻ᵏ C(n,k) = n! / (k! × (n-k)!) Espérance : E(X) = n·p Variance : V(X) = n·p·(1-p)
  • n répétitions identiques et indépendantes
  • p = probabilité de succès à chaque répétition
Exponentielle

Fonction exponentielle eˣ

Propriétés algébriques : eᵃ⁺ᵇ = eᵃ × eᵇ eᵃ⁻ᵇ = eᵃ / eᵇ (eᵃ)ᵇ = eᵃᵇ e⁰ = 1 , e¹ = e ≈ 2,718 Dérivée : (eˣ)' = eˣ (e^u)' = u'·eᵘ (dérivée composée)
Logarithme

Fonction logarithme ln(x)

ln est la réciproque de eˣ : eˡⁿ⁽ˣ⁾ = x et ln(eˣ) = x ln(ab) = ln a + ln b ln(a/b) = ln a - ln b ln(aⁿ) = n·ln a ln(1) = 0 , ln(e) = 1 Dérivée : (ln x)' = 1/x (ln u)' = u'/u
Exponentielle & ln

Variations & limites

  • eˣ : croissante sur ℝ, toujours positive, lim(x→-∞) = 0, lim(x→+∞) = +∞
  • ln x : croissante sur ]0;+∞[, lim(x→0⁺) = -∞, lim(x→+∞) = +∞
  • Croissances comparées : eˣ/xⁿ → +∞ et xⁿ·ln x → 0 quand x→+∞
  • Résoudre eˣ = a : x = ln a (si a > 0)
  • Résoudre ln x = a : x = eᵃ

Exercice — Équation du 2nd degré

Type bac
Soit f(x) = 2x² - 7x + 3.
1) Calculer le discriminant et les racines de f.
2) Donner la forme factorisée de f.
3) Résoudre f(x) ≤ 0.
1) Discriminant : Δ = (-7)² - 4×2×3 = 49 - 24 = 25 > 0
x₁ = (7 - 5) / 4 = 1/2    x₂ = (7 + 5) / 4 = 3

2) Forme factorisée : f(x) = 2(x - 1/2)(x - 3)

3) Signe de f : a = 2 > 0, donc f ≤ 0 entre les racines.
Solution : x ∈ [1/2 ; 3]

Exercice — Suite définie par récurrence

Type bac
Soit (uₙ) définie par u₀ = 5 et uₙ₊₁ = 0,4·uₙ + 3.
1) Montrer que vₙ = uₙ - 5 est géométrique.
2) Exprimer uₙ en fonction de n.
3) Calculer la limite de (uₙ).
1) vₙ₊₁ = uₙ₊₁ - 5 = 0,4uₙ + 3 - 5 = 0,4uₙ - 2 = 0,4(uₙ - 5) = 0,4·vₙ
→ vₙ est géométrique de raison q = 0,4

2) v₀ = u₀ - 5 = 0 → vₙ = 0 × 0,4ⁿ = 0
Donc uₙ = 5 pour tout n (suite constante)

Variante si u₀ = 2 : v₀ = -3, vₙ = -3×0,4ⁿ → uₙ = 5 - 3×0,4ⁿ
3) |q| = 0,4 < 1 donc 0,4ⁿ → 0, lim uₙ = 5

Exercice — Loi binomiale

Type bac
Un joueur marque un penalty avec une probabilité de 0,8. Il tire 6 penalties indépendants.
1) Quelle loi suit le nombre X de penaltys marqués ? Préciser les paramètres.
2) Calculer P(X = 5).
3) Calculer P(X ≥ 5).
1) X suit une loi binomiale B(6 ; 0,8)
(6 épreuves de Bernoulli indépendantes, p = 0,8)

2) P(X=5) = C(6,5) × 0,8⁵ × 0,2¹
= 6 × 0,32768 × 0,2 = ≈ 0,393

3) P(X≥5) = P(X=5) + P(X=6)
P(X=6) = 0,8⁶ ≈ 0,262
P(X≥5) ≈ 0,393 + 0,262 = ≈ 0,655

Exercice — Exponentielle et dérivée

Type bac
Soit f(x) = (2x - 1)·eˣ.
1) Calculer f'(x).
2) Étudier les variations de f.
3) Dresser le tableau de variations complet.
1) f est un produit : u = 2x-1, v = eˣ → u' = 2, v' = eˣ
f'(x) = 2·eˣ + (2x-1)·eˣ = eˣ(2 + 2x - 1) = eˣ(2x + 1)

2) eˣ > 0 toujours → signe de f'(x) = signe de (2x+1)
f'(x) = 0 pour x = -1/2
f'(x) < 0 si x < -1/2 → f décroissante
f'(x) > 0 si x > -1/2 → f croissante

3) Minimum en x = -1/2 : f(-1/2) = (2×(-1/2)-1)×e^(-1/2) = -2/√e ≈ -1,21
